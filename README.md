# ☁️ 워드클라우드 실습실

**자연어 처리 → 단어 빈도 → 워드클라우드**를 세 단계로 실습하는 웹앱입니다.
(초등수학영재프로그램개발 강좌용)

| 단계 | 하는 일 |
|---|---|
| ① 텍스트 입력 | 글 붙여 넣기 / .txt 파일 올리기(UTF-8·CP949) / 예시 불러오기 / 문서 나누기(빈 줄 기준) |
| ② 형태소 분석과 빈도표 | Kiwi로 형태소 분석 → 고른 품사만 세기 → 표에서 단어 빼기·이름 고쳐 합치기 → CSV·엑셀 내려받기, TF-IDF 표 |
| ③ 시각화 | 상위 N개 막대그래프, 워드클라우드(색·배경·모양·크기 기준 선택), PNG 내려받기 |

- 입력한 글은 서버에 **저장하지 않습니다**. 접속한 사람의 브라우저 세션 안에서만 쓰고, 창을 닫으면 사라집니다.
- 한글 글꼴은 저장소 안의 `fonts/NanumGothic.ttf`만 사용합니다(시스템 글꼴 사용 안 함).

## 폴더 구성

```
wordcloud/
├─ app.py                 ← 앱 전체 (이 파일 하나)
├─ requirements.txt       ← 필요한 파이썬 패키지 목록
├─ .streamlit/config.toml ← 화면 색·글자 크기 설정
└─ fonts/
   ├─ NanumGothic.ttf     ← 한글 글꼴 (꼭 필요)
   ├─ OFL.txt             ← 글꼴 라이선스 원문
   └─ README.md           ← 글꼴을 받아 넣는 방법
```

글꼴 파일이 없으면 앱 위쪽에 빨간 안내가 뜨고 그래프·워드클라우드가 그려지지 않습니다.
글꼴을 받아 넣는 방법과 라이선스(SIL OFL 1.1)는 [fonts/README.md](fonts/README.md)를 보세요.

## ① 내 컴퓨터에서 실행하기

### 1. 파이썬 설치 (처음 한 번)
1. <https://www.python.org/downloads/> 에서 **Python 3.12**(또는 3.11~3.13)를 내려받아 설치합니다.
2. 설치 첫 화면에서 **"Add python.exe to PATH"** 에 꼭 체크합니다.

### 2. 필요한 패키지 설치 (처음 한 번)
1. 이 폴더(`wordcloud`)를 파일 탐색기로 엽니다.
2. 주소 표시줄에 `cmd`라고 쓰고 Enter를 누르면, 이 폴더에서 명령 프롬프트가 열립니다.
3. 아래 명령을 입력합니다. (몇 분 걸릴 수 있어요)

```bash
pip install -r requirements.txt
```

### 3. 앱 실행 (쓸 때마다)

```bash
streamlit run app.py
```

- 잠시 뒤 웹브라우저가 열리며 `http://localhost:8501` 에서 앱이 보입니다.
- 처음 실행할 때는 형태소 분석기(Kiwi)를 준비하느라 몇 초 걸립니다.
- 끝낼 때는 명령 프롬프트 창에서 `Ctrl + C`를 누르거나 창을 닫습니다.

> 같은 와이파이에 있는 학생들은 실행 화면에 나오는 `Network URL`(예: `http://192.168.0.10:8501`)로 접속할 수도 있습니다.
> 학교 네트워크에서는 막혀 있는 경우가 많으니, 수업용으로는 아래 ②의 무료 배포를 권장합니다.

## ② GitHub에 올려 Streamlit Community Cloud로 무료 배포하기

### 가. GitHub 저장소 만들기
1. <https://github.com> 에 가입하고 로그인합니다.
2. 오른쪽 위 **＋ → New repository** 를 누릅니다.
3. **Repository name**에 `wordcloud-class` 처럼 영어 이름을 적습니다.
4. **Public**(공개)을 고릅니다. (무료 배포는 공개 저장소가 가장 간단합니다)
5. **Create repository** 를 누릅니다.

### 나. 파일 올리기
1. 새 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
2. 파일 탐색기에서 아래 항목을 한꺼번에 끌어다 놓습니다.
   - `app.py`
   - `requirements.txt`
   - `README.md`
   - `fonts` 폴더 (안의 `NanumGothic.ttf`, `OFL.txt`, `README.md` 포함)
   - `.streamlit` 폴더 (안의 `config.toml`)
3. 아래쪽 **Commit changes** 를 누릅니다.
4. 저장소 첫 화면에 `fonts/NanumGothic.ttf` 와 `.streamlit/config.toml` 이 보이는지 확인합니다.
   - 폴더 끌어다 놓기가 안 되면 **Add file → Create new file** 에서 이름 칸에 `.streamlit/config.toml` 처럼
     폴더 이름과 `/`를 함께 적으면 폴더가 만들어집니다. 글꼴은 `fonts/` 폴더 화면에서 **Upload files**로 올립니다.

### 다. Streamlit Community Cloud에 배포
1. <https://share.streamlit.io> 에 들어가 **Continue with GitHub** 로 로그인하고, GitHub 연결을 허용합니다.
2. 오른쪽 위 **Create app** → **Deploy a public app from GitHub**(또는 "Yup, I have an app")를 고릅니다.
3. 다음과 같이 채웁니다.
   - **Repository**: `내아이디/wordcloud-class`
   - **Branch**: `main`
   - **Main file path**: `app.py`
   - **App URL**: 원하는 주소를 적을 수 있습니다(예: `snue-wordcloud`).
4. **Advanced settings** 에서 **Python version**을 **3.12** 로 고르고 저장합니다.
5. **Deploy** 를 누릅니다. 처음에는 패키지를 설치하느라 3~5분 걸립니다.
6. 완료되면 `https://(정한이름).streamlit.app` 주소로 앱이 열립니다.

### 라. 고칠 때
- GitHub 저장소에서 `app.py` 등을 고치고 **Commit changes** 하면, 1~2분 안에 앱에 자동으로 반영됩니다.
- 앱 오른쪽 아래 **Manage app** 에서 오류 기록(로그)을 보거나 **Reboot app**으로 다시 시작할 수 있습니다.

## ③ 수업 중 학생들이 링크로 접속해 쓰는 방법

1. **수업 10분 전에 교사가 먼저 링크를 열어 둡니다.**
   무료 앱은 한동안 아무도 접속하지 않으면 잠들어 있어서, "Yes, get this app back up!" 버튼을 눌러 깨워야 합니다(1분 정도).
2. 링크를 학생들에게 나눠 줍니다. 칠판에 짧은 주소를 적거나, QR 코드로 만들어 화면에 띄우면 편합니다.
3. 학생들은 로그인 없이 웹브라우저(크롬·엣지·웨일, 태블릿도 가능)로 접속합니다.
4. **학생마다 따로 작업합니다.** 한 학생이 입력하거나 표를 고쳐도 다른 학생 화면에는 영향을 주지 않습니다.
   사용자 사전도 학생마다 따로 적용됩니다.
5. 진행 예시
   - 예시 1(영화 댓글)을 불러와 **형태소로 쪼갠 결과 보기**에서 `감동적인 → 감동 + 적 + 이 + ㄴ` 처럼 나뉘는 모습을 함께 봅니다.
   - 사이드바에서 품사·불용어를 바꿔 보며 빈도표가 어떻게 달라지는지 이야기합니다.
   - 빈도표에서 단어 이름을 고쳐 합치거나 [포함]을 꺼서 워드클라우드를 다듬습니다.
   - 예시 2(청바지 후기)로 **TF-IDF**를 보고, 교과서식 n/DF와 log(N/DF)를 비교합니다.
   - 결과 PNG, 빈도표 CSV·엑셀을 내려받아 활동지에 붙입니다.
6. 주의할 점
   - 새로 고침(F5)하거나 창을 닫으면 입력한 글과 편집 내용이 사라집니다. 필요한 결과는 내려받아 두세요.
   - 무료 서버라 한 반(30명 안팎)이 동시에 쓰는 정도가 적당합니다. 아주 긴 글(수십 쪽)은 앞의 20만 자만 분석합니다.

## 검수용 예시와 실제 분석 결과

앱에 내장한 두 예시를 실제로 돌려 본 결과입니다. (kiwipiepy 0.24 기준)

### 예시 1: 영화 댓글 (명사·동사·형용사 포함, 불용어 기본값)

| 단어 | 영화 | 감동 | 긴장감 | 눈물 | 보다 | 실망 | 지루하다 | 추천 |
|---|---|---|---|---|---|---|---|---|
| 빈도 | 4 | 3 | 1 | 1 | 1 | 1 | 1 | 1 |

- 불용어로 빠진 말: `있다` 2회, `없다` 1회 → 요구 사항과 같습니다.

### 예시 2: 청바지 후기 (문서 나누기 켬, 명사·형용사 포함)

| 단어 | 청바지 | 추천 | 디자인 | 좋다 | 가격 | 신축성 | 예쁘다 | 저렴하다 |
|---|---|---|---|---|---|---|---|---|
| 빈도 | 4 | 4 | 3 | 3 | 2 | 1 | 1 | 1 |
| DF | 3 | 3 | 2 | 2 | 2 | 1 | 1 | 1 |
| 교과서식 IDF (n/DF) | **1** | **1** | 1.5 | 1.5 | 1.5 | **3** | **3** | **3** |

- 문서별 TF·IDF 최댓값: 문서1 `예쁘다·저렴하다`(3), 문서2 `디자인`(3), 문서3 `좋다·신축성`(3)
- log₁₀(N/DF)를 고르면 세 문서 모두에 나온 `청바지`·`추천`(DF=3)의 IDF가 0이 되고, `신축성`·`예쁘다`·`저렴하다`는 log₁₀3 ≈ 0.477이 됩니다.

### 형태소 분리 방식 때문에 생기는 차이 (원인 설명)

Kiwi는 낱말을 아래처럼 쪼갭니다. 앱은 이 결과를 그대로 화면(🔍 형태소로 쪼갠 결과 보기)에 보여 주고, 표에는 몇 가지 규칙으로 정리해 셉니다.

| 원래 말 | Kiwi 분석 | 앱이 세는 방식 |
|---|---|---|
| 감동적인 | 감동/NNG + 적/XSN + 이/VCP + ㄴ/ETM | `감동`(명사)만 셈 → 감동이 3회가 됨. `-적`은 접미사라 세지 않음 |
| 지루해서 | 지루/XR(어근) + 하/XSA + 어서/EC | 어근+하 를 합쳐 형용사 `지루하다` 로 셈 |
| 추천해요 | 추천/NNG + 하/XSV + 어요/EF | `추천`(명사) + `하다`(동사)로 셈. `하다`는 불용어라 빠짐 |
| 볼 (수) | 보/VV + ㄹ/ETM | 기본형 `보다` 로 셈 |
| 좋아요, 좋고, 좋아서 | 좋/VA + 어미 | 모두 기본형 `좋다` 로 합쳐 셈 |
| 없이는 | 없이/MAG(부사) + 는/JX | 부사라서 `없다`로 세지 않음 → 불용어 `없다`는 1회(없는)만 빠짐 |
| 영화예요, 실망이에요 | 영화/NNG + 이/VCP + 에요/EF | `이다`(VCP)는 고를 수 있는 품사가 아니라 세지 않음 |
| 신축성과 | **신축/NNG + 성/XSN** | 사전에 `신축성`이 없어 `신축`으로 나뉨 (아래 참고) |
| 다 좋아요 | 다/MAG | 부사 `다`는 부사를 켰을 때만 셈 |

- **신축성**: Kiwi 기본 사전으로는 `신축 + 성`으로 나뉘어 `신축` 1회로 셉니다.
  그래서 예시 2를 불러오면 **사용자 사전에 `신축성`을 미리 넣어** `신축성` 1회가 되도록 했습니다.
  사이드바 사용자 사전에서 `신축성`을 지우면 `신축`으로 바뀌는 것을 학생들과 확인해 볼 수 있습니다.
- **추천해요의 `하다`**: 예시 2는 동사(VV)를 고르지 않았기 때문에 `하다`는 품사 단계에서 이미 빠집니다.
  사이드바에서 동사를 켜면 `불용어로 빠진 말: 하다 2회` 로 표시됩니다.
- **명사 + 하다 동사**: `추천하다`, `행복하다` 처럼 명사 뒤에 붙은 `하다`는 Kiwi가 명사와 접미사로 나누므로,
  앱에서도 `추천` + `하다` 로 셉니다. (어근(XR)으로 분석되는 `지루하다`, `깨끗하다` 등은 한 단어로 합칩니다.)

## 기술 메모 (관리자용)

- Kiwi 객체는 메모리를 300MB 가까이 쓰기 때문에 `st.cache_resource`로 **서버 전체에 하나만** 만듭니다.
  사용자 사전 단어는 `add_user_word`로 이 Kiwi에 등록하고, 분석할 때 다른 사람이 등록한 단어는
  `blocklist`로 막아서 **사용자 사전이 접속자마다 따로 적용**되게 했습니다.
- 빈도표 편집(포함 끄기, 이름 고치기)은 `st.session_state`에 "고친 이름 목록·뺀 단어 목록"으로 저장하고,
  분석을 다시 해도 이 목록을 다시 적용하므로 옵션을 바꿔도 편집 내용이 유지됩니다.
  예시를 새로 불러오거나 파일을 올리면 편집 내용은 처음으로 돌아갑니다.
- TF·IDF로 워드클라우드를 그릴 때는 단어마다 **문서별 TF·IDF를 더한 값**을 크기로 씁니다.
